# v5.0 — THE COMPANY OWNS YOU

Authorized 4 November 2026. This is the complete scope accepted in chat; v6 follows cumulatively. Current production v4.0.1 is preserved before assembly. No collection reset, health-rule change, or loss of existing characters, art, scores or unlocks.

1. **Briefing and headquarters:** route cards show objective, ecology, signature reward and starting rules; a headquarters dossier tracks confirmed district clears and equipment blueprints, with a direct practice entrance. Every advanced start remains a fresh kit. Training uses the existing isolated practice simulation and grants nothing.
2. **District infrastructure:** each sector has an optional switch with a different benefit (seismic dampener, drainage bypass, archive authorization, emergency lighting). A visible sealed research-room gate opens; completing the optional work awards a district-flavoured modification and supplies. Switches and gate state are simulation data, not decoration. Main missions remain distinct and intact.
3. **Readable builds:** explicit damage, volleys, projectiles, charge behaviour, status effects, calibration and installed features; derive build nicknames from stat tags, without bespoke pair interaction code. Display exact before/after modification changes using the existing compiler. Backpack remains editable while paused.
4. **Looting:** permanent important drop markers, nearby pickup list with type and rarity, reward/build comparison, pause while inspecting; ordinary drops remain available during quiet phases. Clearing an assault grants a deliberate scavenging phase ended by player choice. Cleared buildings identify safe inspection zones when enemies are absent. Transit can be held for looting and explicitly continued.
5. **Boss personalities:** two optional vault bosses, The Mandatory Meeting and Expense Report, have separate attack patterns, staged tells, vulnerability windows, bespoke models, introductions and guaranteed rewards. All guardians use finite catalogue HP; actual summon path stays regression-tested.
6. **Atmosphere:** stronger district identities, infrastructure/gate models, contextual corporate transmissions and original ambient audio, reduced-motion aware. No external/licensed art dependency.
7. **Reliability:** independent daily text and art budgets, honest reset metadata, bounded persistent image caching, request deduplication, no broken text feed after art limit; retain all admission, device, privacy and write receipts. Studio local recovery is preserved. Adjustable touch size and position persist per device.

Acceptance: actual briefing→practice/mission→optional switch→opened room→reward→fight→scavenge→guardian→transit; all supported bosses finite, deterministic simulation, build compiler regressions, 320px/390px/desktop browser checks, chat/art independent budget boundary tests and permission denials. No fabricated production social/health/game events.
