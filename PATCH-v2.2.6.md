# v2.2.6 — time to chat out the nicotine

- **A readable On shift roster.** Each character has a vertical row with their avatar, name, live nicotine-free timer and latest report. Every character is included; the old five-avatar preview limit is gone. Games-only characters display Games only instead of a quit timer.
- **A small sign of recent activity.** A subtle exclamation appears beside a name for one hour after a shared nicotine check-in. The row says what their latest report was and when. The indicator expires automatically and never fabricates reports.
- **Rank gets its own space.** Your rank & milestones is an always-visible, quiet card directly below nicotine check-ins and above On shift. The progress bar, next rank, all-ranks button and journey link stay together.
- **Cleaner structure.** Consistent card boundaries, full names that wrap, aligned timers and compact report text replace the horizontal avatar strip and loose milestone section. Phone nicotine controls still precede social features; Crew updates remains collapsed by default on phones.

No database migration or data changes. Existing quit clocks, reports, drawing originals, game records, boss caps and the rotating ballot are preserved. The patch name is unchanged.
