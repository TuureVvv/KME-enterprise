# KILLME ENTERPRISE

A private, free friends-only nicotine quit tracker and goblin arcade.

Play: https://tuurevvv.github.io/KME-enterprise/

Version 4 adds an illustrated arcade, a 48-hour vote for the next newly developed game, and Urge Breaker: a short bank-anytime side game. No votes means the current arcade stays.

GitHub Pages serves the static files. Supabase stores group data behind admission checks and RLS. Only the publishable browser key belongs in config.js; never commit shared passwords or owner keys.

See ARCADE-DEVELOPER.md for the vote/build/publish workflow.
