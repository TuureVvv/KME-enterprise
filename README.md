# KILLME ENTERPRISE · v6.0

**AFTER HOURS: HOSTILE TAKEOVER.** Management has left the building. The crew kept the keys.

A private friend-group nicotine support space with explicit optional check-ins, Drawing Studio, BLACKSITE, Rotating Arcade, chat, profiles and cosmetic collections. v6 adds an after-hours headquarters, six-floor cooperative operations, a dedicated artwork exhibition, Quiet Room, device-local Private Logbook, an original daily routing puzzle, personal palettes and a searchable room directory. Includes the complete v5 BLACKSITE briefing/infrastructure/boss/looting/build update.

[v6 patch notes](PATCH-v6.0.md) · [v5 patch notes](PATCH-v5.0.md) · [Design and implementation](src/v60/DESIGN-IMPLEMENTATION-PLAN.md) · [Validation](src/v60/VALIDATION.md)

Existing characters, reports, artwork, scores, unlocks, auras and wallet balances are retained. No new aura reset or nicotine-reward change. Nicotine sharing remains optional; creative modes and games never invent a health report. The shared character picker is a friend-group trust system, not individual identity verification.

The new operation uses verified existing game/art/community activity with character AND device caps, persisted decisions and idempotent action receipts. Text and artwork have independent bounded response allowances; artwork is lazily loaded and cached on-device. Private Logbook and coping cards stay in the browser and provide explicit export/storage notices. Gallery files keep the existing seven-day lifecycle. BLACKSITE combat worlds are not saved on reload; confirmed progression remains.

112 isolated check groups include 750 modifier compositions and 200 deterministic puzzle seeds, complete objective/guardian paths, drawing recovery/export and phone layouts. No fabricated real crew records were used. Physical phones were not manually tested. Readable release extensions are under `src/v50` and `src/v60`; compiled static assets at the root are the deployed application. Full legacy assembly dependencies remain in the project workspace.

GitHub Pages hosts the static app. Supabase provides private admitted-group data. This is a free friend-group project with no paid cosmetics, gambling, trading or cash prizes.
